**Smart Irrigation Agent** is a modern, responsive, commercial-grade IoT & AI-powered agricultural technology web application designed specifically to intelligently monitor campus garden conditions, optimize water distribution, prevent underwatering/overwatering, and autonomously generate precision irrigation schedules based on soil moisture sensors, weather forecasts, and agronomic AI models.

---

## 🌟 Key Features

### 1. 🌿 Real-Time Campus Dashboard
- **Live Garden KPIs**: Total zones (5), active irrigation valves, average soil moisture (%), ambient temperature & humidity, daily water consumed, water saved through AI scheduling, and next scheduled irrigation time.
- **Interactive Multi-Zone Charts**: Volumetric soil moisture trends across zones with safe threshold bands using Recharts.
- **Microclimate Temperature & Humidity**: Real-time diurnal temperature cycle and Vapor Pressure Deficit (VPD).
- **Water Consumption vs Savings**: Daily bar chart comparing liters delivered vs water conserved.
- **Zone Quick Grid**: Live status cards for all 5 campus zones with visual moisture gauges, battery indicators, and quick 10-minute water test toggles.
- **Natural Language Garden Health Summary**: Generated by the AI Engine with real-time agronomic status.

### 2. 🗺️ Garden Zone Management
- Pre-seeded campus zones:
  1. **Botanical Garden** (Exotic Ferns, Palms & Orchids | Loam Rich Organic | 250 m²)
  2. **Flower Garden** (Roses, Marigolds & Petunias | Sandy Loam | 180 m²)
  3. **Herbal Garden** (Mint, Basil, Rosemary & Thyme | Sandy Soil | 120 m²)
  4. **Lawn Area** (Bermuda Turf Grass | Clay Loam | 600 m²)
  5. **Vegetable Garden** (Tomatoes, Peppers, Lettuce & Spinach | Silty Loam | 320 m²)
- **Zone Operations**: Add new zones, edit plant species, change soil medium, configure surface area, calibrate minimum/maximum moisture thresholds, inspect individual zone telemetry, and delete zones.

### 3. 🤖 AI Irrigation Scheduling Engine (Core Feature)
- **FAO-56 Penman-Monteith Evapotranspiration**: Replaces rigid mechanical timers with scientific daily water demand calculations ($ET_c = K_c \times ET_0$).
- **Multi-Variable Decision Matrix**:
  - **Rain Shield**: Automatically bypasses/skips irrigation when weather forecast predicts $\ge 55\%$ precipitation probability, preventing water wastage and waterlogging.
  - **Evaporation Mitigation**: Automatically defers daytime watering to dusk (18:30) or dawn (06:00) during heat conditions to eliminate 35-40% evaporative loss.
  - **Emergency Wilting Point Guard**: Immediately pulses water if root-zone moisture drops below critical limits ($< 22\%$) to preserve plant cellular integrity.
  - **Precise Volume & Duration Engine**: Computes exact water volume in liters based on moisture deficit, root depth, surface area, and soil retention properties.
- **One-Click AI Optimizer**: Re-evaluates all microclimates with real-time feedback.

### 4. 💬 AI Agronomic Chat Assistant
- Conversational botanical chatbot that understands campus garden context, sensor readings, and weather dynamics.
- Suggestion chips:
  - *"Calculate water saved this month"*
  - *"Why is Lawn Area scheduled for dusk?"*
  - *"Check tomorrow's rain forecast"*
  - *"What are the ideal thresholds for Ferns?"*

### 5. 🚰 Manual Solenoid Valve Control Panel
- Individual solenoid valve controls with safety auto-off duration timers (5 min, 10 min, 15 min, 30 min).
- **Master Emergency Shutoff**: Instantly closes all active valves across the campus garden to prevent accidental flooding.

### 6. 🌤️ Campus Weather Station
- Hyperlocal weather metrics: Ambient temperature, relative humidity, rain probability, wind speed, solar radiation ($W/m^2$), UV Index, and reference evapotranspiration ($ET_0$).
- 7-day microclimate forecast with daily rain probability indicators.

### 7. 📡 IoT Hardware Integration & Virtual Simulator
- **Interactive Virtual IoT Simulator**:
  - Simulate Rain Showers (rapidly restores moisture across all zones).
  - Simulate Afternoon Heatwaves (spikes temperature to 38°C and accelerates soil evaporation).
  - Continuous background physics loop (4-second real-time tick).
  - Sensor reset to baseline.
- **ESP32 Firmware**: Complete production-ready Arduino C++ sketch (`esp32_smart_irrigation.ino`) for ESP32 with DHT22, analog Capacitive Soil Moisture Sensor v1.2, and 5V Relay module.

## 🚀 Quick Start Guide

### Prerequisites
- **Node.js** (v18 or higher) and **npm**
- **Python** (v3.10 or higher)

### Option 1: Quick 1-Click Launch (Windows)
Double-click `start_all.bat`. This automatically starts both the FastAPI backend and the Vite frontend.
- **Frontend Dashboard**: [http://localhost:5173](http://localhost:5173)
- **FastAPI Interactive Docs**: [http://localhost:8000/docs](http://localhost:8000/docs)

---

### Option 2: Manual Step-by-Step Setup

#### 1. Start Backend Server
```bash
# Navigate to backend directory
cd backend

# Create and activate virtual environment (optional but recommended)
python -m venv venv
# On Windows:
.\venv\Scripts\activate
# On macOS/Linux:
source venv/bin/activate

# Install dependencies
pip install -r requirements.txt

# Run the FastAPI server
uvicorn main:app --host 0.0.0.0 --port 8000 --reload
```

The database `smart_irrigation.db` is automatically created and populated with default campus garden zones on the first run.

#### 2. Start Frontend Server
In a new terminal window:
```bash
# Navigate to frontend directory
cd frontend

# Install packages
npm install

# Start Vite dev server
npm run dev
```

Open your browser at **`http://localhost:5173`**.

## 🔌 ESP32 Microcontroller Setup

### Pinout Wiring Diagram

| Component | Pin | ESP32 GPIO | Description |
|---|---|---|---|
| **Capacitive Soil Sensor** | VCC | 3.3V | Power supply |
| | GND | GND | Ground |
| | AOUT | **GPIO 34** (ADC1) | Analog voltage representing soil moisture |
| **DHT22 Sensor** | VCC | 3.3V | Power supply |
| | GND | GND | Ground |
| | DATA | **GPIO 4** | Digital bidirectional 1-wire bus |
| **Relay Module** | VCC | 5V | Coil power supply |
| | GND | GND | Ground |
| | IN | **GPIO 26** | Active LOW relay trigger (Solenoid Valve) |
| **Status Indicator** | - | **GPIO 2** | Built-in Blue LED |

### Flashing Firmware
1. Open `backend/esp32_firmware/esp32_smart_irrigation.ino` in the Arduino IDE.
2. In Tools $\rightarrow$ Manage Libraries, install:
   - `DHT sensor library` by Adafruit
   - `ArduinoJson` (v6 or v7) by Benoît Blanchon
3. Update `WIFI_SSID`, `WIFI_PASS`, and `SERVER_URL` with your local network details.
4. Select board **ESP32 Dev Module** and upload.

## 🌿 Agronomic AI Decision Formulas

### 1. Evapotranspiration ($ET_c$)
$$ET_c = K_c \times ET_0$$
Where:
- $ET_0$: Reference evapotranspiration estimated via Hargreaves/Penman-Monteith equation based on solar radiation ($W/m^2$), temperature ($^\circ C$), and relative humidity (%).
- $K_c$: Crop coefficient matrix:
  - *Exotic Ferns & Palms*: $K_c = 0.85$
  - *Roses & Flowering Shrubs*: $K_c = 0.95$
  - *Culinary Herbs*: $K_c = 0.70$
  - *Turf Grass (Lawn)*: $K_c = 1.05$
  - *Vegetable Garden*: $K_c = 1.15$

### 2. Precise Water Volume Requirement
$$\text{Water Needed (Liters)} = \text{Area} (m^2) \times \text{Root Depth} (m) \times \left(\frac{\text{Target Moisture} - \text{Current Moisture}}{100}\right) \times 1000 \times K_c \times \eta_{\text{soil}}$$

### 3. Rain Ingestion Shield
$$\text{IF } P(\text{rain}) \ge 55\% \text{ AND } \text{Forecast Precip} \ge 2.5\text{ mm} \implies \text{DEFER IRRIGATION (Save 100\% Water)}$$
